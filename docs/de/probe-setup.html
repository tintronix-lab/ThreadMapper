Eine ThreadMapper-Sonde bauen

Eine Sonde ist eine kleine Platine in Ihrem WLAN, die den Funk misst, den sich Ihr Smart Home teilt: wie stark jeder Thread-Kanal belegt ist, welche WLAN-Netzwerke darauf liegen und, wo sie Ihrem Thread-Netz beitreten kann, das Netz so, wie seine eigenen Router es melden. ThreadMapper liest sie über Ihr eigenes Netzwerk aus.

Ein Bauteil, etwa zehn Minuten, kein Löten. Die Sonde gehört zu ThreadMapper Pro.

Lesen Sie das, bevor Sie die Platine kaufen

Was sie in Ihrem Zuhause lesen kann

Das Messen funktioniert in jedem Zuhause. Um das Netz auszulesen, muss die Sonde Ihrem Thread-Netzwerk beitreten, und ob sie das kann, hängt davon ab, was dieses Netzwerk betreibt.

Ihr ZuhauseKanalrauschen und das WLAN auf jedem KanalDas Thread-Netz selbst
Border Router von Apple oder Google und sonst nichtsJaNein. Keiner von beiden lässt Sie die Zugangsdaten Ihres Thread-Netzwerks herausholen. Apple gibt einer App das Recht, sie zu lesen, nur dann, wenn ihr Hersteller auch einen zertifizierten Border Router herstellt, und der Hersteller von ThreadMapper tut das nicht.
Dasselbe, mit Home AssistantJaJa. Die Companion-App von Home Assistant kann die Zugangsdaten hineinkopieren, und Sie kopieren sie von dort auf die Sonde (Schritt 5).
Ein eigener OpenThread Border RouterJaJa. Lesen Sie sie dort aus (Schritt 5).

Wenn die erste Zeile Ihr Zuhause ist, zeichnet die Sonde Ihr Netz nicht. Sie misst trotzdem, was kein Telefon messen kann: das Rauschen auf jedem der sechzehn Thread-Kanäle, alle fünf Minuten, und welche WLAN-Netzwerke dahinterstehen. Entscheiden Sie auf dieser Grundlage, bevor Sie kaufen.

Schritt 1 — Die Firmware installieren

  1. Schließen Sie die Platine an den Computer an.
  2. Klicken Sie unten auf Firmware der Sonde installieren und wählen Sie den Port namens USB JTAG/serial debug unit.
  3. Klicken Sie auf Install ThreadMapper Probe. Es wird gefragt, ob das Gerät gelöscht werden soll: Bei einer neuen Platine setzen Sie das Häkchen bei Erase device. Dann Next und Install.

Nur bei einer neuen Platine. Das Löschen nimmt alles mit, was einer Sonde mitgeteilt wurde: ihr WLAN, ihren Schlüssel und ihr Thread-Netzwerk. Eine Sonde, die bereits funktioniert, wird stattdessen aktualisiert (siehe Aktualisieren), und wenn das Installationsprogramm bei einer solchen danach fragt, lassen Sie das Kästchen leer.

Dieser Browser kann nicht auf einen seriellen USB-Port zugreifen. Öffnen Sie diese Seite in Chrome, Edge oder Firefox, auf einem Computer. Das Installationsprogramm funktioniert nur auf einer Seite, die über HTTPS geöffnet wurde.

Das dauert ein, zwei Minuten und endet mit Installation complete! Klicken Sie auf Next. Das Fenster des Installationsprogramms selbst ist auf Englisch.

Steht der Port nicht in der Liste, liegt es fast immer am Kabel. Andernfalls halten Sie die Taste B der Platine gedrückt, während Sie sie anschließen, und versuchen es erneut.

Keiner dieser Browser? esptool von Espressif leistet dasselbe. Eine Erstinstallation, die alles löscht, was auf der Platine war:

esptool.py --chip esp32c6 write_flash 0x0 threadmapper-probe-full.bin

Eine Aktualisierung, die der Sonde lässt, was ihr mitgeteilt wurde:

esptool.py --chip esp32c6 write_flash 0x20000 threadmapper-probe.bin

Die beiden Images sind threadmapper-probe-full.bin und threadmapper-probe.bin. Öffnen Sie danach den seriellen Port der Platine mit einem beliebigen Terminalprogramm und geben Sie der Sonde ihr WLAN, indem Sie es eintippen (Schritt 2, Ohne die Liste).

Schritt 2 — Der Sonde Ihr WLAN geben

Nach einer Erstinstallation mit gesetztem Häkchen bei Erase device geht das Installationsprogramm von selbst zu Configure Wi-Fi weiter. Sehen Sie stattdessen seine Liste mit Auswahlmöglichkeiten, klicken Sie dort auf Connect to Wi-Fi.

Die Sonde listet die Netzwerke auf, die sie hört.

  1. Wählen Sie unter Network Ihres aus.
  2. Geben Sie sein Passwort ein.
  3. Klicken Sie auf Connect.

Das Installationsprogramm meldet Trying to connect, was fast eine Minute dauern kann, und dann Device connected to the network! Die LED der Sonde leuchtet dann und bleibt an. Klicken Sie auf Continue.

Die Sonde behält ein Netzwerk erst, wenn sie ihm beigetreten ist. Unable to connect bedeutet, dass sie es versucht hat und nicht hineingekommen ist: fast immer das Passwort, manchmal ein zu weit entfernter Router. Der Versuch hat nichts geändert: Eine Sonde, die vorher ein Netzwerk hatte, hat es noch und kehrt dorthin zurück. Versuchen Sie es erneut.

Ihr Netzwerk steht nicht in der Liste? Die Sonde hat keinen 5-GHz-Funk, ein Netzwerk nur auf 5 GHz ist also nicht dabei. Ebenso wenig ein Netzwerk, das seinen Namen verbirgt: Wählen Sie Join other… und geben Sie den Namen ein.

Das Passwortfeld verbirgt, was Sie eingeben. Name und Passwort gehen durch das Kabel zur Platine, die sie in ihrem eigenen Speicher behält und das Passwort in kein Log schreibt.

Ohne die Liste

Bietet das Installationsprogramm kein Connect to Wi-Fi an, hat es die Sonde nicht antworten hören: Schließen Sie sein Fenster, klicken Sie erneut auf die Installationsschaltfläche und wählen Sie den Port.

Die Sonde kann ihr Netzwerk auch an ihrer Konsole bekommen, unter Logs & Console oder in einem beliebigen Terminalprogramm an ihrem Port. Geben Sie wifi ein und drücken Sie die Eingabetaste (Return). Die Zeilen, die mit > beginnen, sind das, was Sie eingeben:

> wifi
Network name? Type it and press Return.
> My network
Password? The probe does not write it back. Return alone for a network without one.
> my password
stored: "My network", with a password of 11 characters.
Restarting to join it. The light stays on once it has.

Nichts braucht Anführungszeichen, und Buchstaben wie å, ä und ö sind in Ordnung. Die Sonde gibt das Passwort nicht wieder aus. Die Seite dagegen zeigt es an, während Sie tippen, und behält es in ihrem Log, bis Sie das Fenster schließen: Es ist Ihr eigener Bildschirm, schauen Sie also zuerst über Ihre Schulter.

Bekommt die Sonde ein Netzwerk auf diesem Weg, startet sie neu, um ihm beizutreten, und hat es vorher nicht ausprobiert. Kehrt ihre LED zu einem kurzen Blinken alle zwei Sekunden zurück, hat sie es zehnmal versucht, konnte nicht beitreten und hat das Netzwerk vergessen.

Schritt 3 — Die App verbinden

Warten Sie, bis die LED dauerhaft leuchtet. Öffnen Sie auf dem iPhone ThreadMapper und gehen Sie zu Einstellungen → ThreadMapper-Sonde. Ist das Telefon im selben WLAN, steht die Sonde unter In diesem Netzwerk: Wählen Sie sie aus. Verbindung testen sagt dann, was die Sonde ist und wie es um sie steht.

Listet die App sie nicht auf, fragen Sie die Sonde, wo sie ist: Schließen Sie das Fenster des Installationsprogramms, klicken Sie erneut auf die Installationsschaltfläche, wählen Sie den Port, öffnen Sie Logs & Console und geben Sie status ein. Eine der Zeilen ist die Adresse, die Sie in die App eingeben:

in the app: http://192.168.1.50:8099

Ihr Router gibt der Sonde vielleicht eines Tages eine andere Adresse. Die App erkennt die Sonde an mehr als ihrer Adresse: Ist die App geöffnet und das Telefon im selben WLAN, findet sie die Sonde von selbst wieder.

Das Kabel hat seine Arbeit getan. Ziehen Sie die Platine ab und stecken Sie sie an ein Ladegerät, irgendwo in der Mitte des Zuhauses statt hinter dem Router: Die Sonde hört, was in ihrer Nähe ist.

Schritt 4 — Ihrem iPhone den Schlüssel geben

Eine Sonde ohne Schlüssel antwortet jedem in Ihrem WLAN. Das schließt die Namen der WLAN-Netzwerke ein, die sie hört, und Anfragen, die ihr Funkmodul jeweils für Sekunden vom Kanal Ihres Netzes nehmen.

Drücken Sie die Taste B der Platine zweimal direkt hintereinander. (Nicht R: Die startet die Sonde neu.) Die LED blinkt zweimal pro Sekunde, drei Minuten lang oder bis ein Telefon den Schlüssel abgerufen hat. Tippen Sie in der App unter Einstellungen → ThreadMapper-Sonde auf Schlüssel abrufen.

Von da an tut die Sonde das, was ihre Funkzeit kostet, nur für ein Telefon, das den Schlüssel hat. Der Schlüssel beweist, wer fragt; er verbirgt nichts. Antworten gehen weiterhin unverschlüsselt über Ihr WLAN, und der Schlüssel ebenso, einmal, wenn ein Telefon ihn erhält.

Immer nur ein Telefon hat den Schlüssel. Ein zweites Telefon, das ihn erhält, nimmt ihn dem ersten.

Schritt 5 — Der Sonde Ihr Thread-Netzwerk geben

Überspringen Sie das, wenn Ihr Zuhause die erste Zeile der Tabelle oben ist.

Die Sonde tritt einem Thread-Netzwerk mit dessen aktivem Datensatz (Active Dataset) bei, einer Zeichenfolge aus rund zweihundert Hexadezimalziffern, die den Schlüssel des Netzwerks enthält.

  • Home Assistant: Öffnen Sie dessen Thread-Seite, Settings → Connectivity → Thread, oder in älteren Versionen Settings → Devices & services → Thread → Configure (die Menünamen sind die englischen von Home Assistant). Neben Ihrem Netzwerk ist eine Informationstaste, und was sie anzeigt, endet mit Active dataset TLVs: Kopieren Sie das. Gehört das Netzwerk zu Apple Home, muss Home Assistant es erst bekommen: Öffnen Sie dieselbe Seite in der Companion-App auf Ihrem iPhone und wählen Sie Send credentials to Home Assistant.
  • OpenThread Border Router: sudo ot-ctl dataset active -x

Schließen Sie die Sonde wieder an den Computer an, klicken Sie oben auf die Installationsschaltfläche, wählen Sie ihren Port und öffnen Sie Logs & Console, ohne etwas zu installieren. Geben Sie thread dataset ein, drücken Sie die Eingabetaste und fügen Sie den Datensatz ein, wenn die Sonde danach fragt:

> thread dataset
Dataset, as hex? The probe does not write it back.
> 0e080000000000010000000300001935060004001fffe0...
stored: "MyHome", channel 25. Restarting to join it.

Innerhalb weniger Minuten sagt die App unter Einstellungen → ThreadMapper-Sonde, dass die Sonde in ihrem Thread-Netz ist.

Der Datensatz ist der Schlüssel zu Ihrem Thread-Netzwerk. Die Sonde gibt ihn nicht wieder aus, aber die Seite, in die Sie ihn einfügen, zeigt ihn an und behält ihn in ihrem Log, bis Sie das Fenster schließen. Die Sonde behält ihn in ihrem eigenen Speicher, der nicht verschlüsselt ist: Wer die Platine an sich nimmt, kann ihn auslesen.

Aktualisieren

Eine neue Firmware erscheint auf dieser Seite. Schließen Sie die Sonde an den Computer an, klicken Sie auf die Installationsschaltfläche und wählen Sie den Port. Das Installationsprogramm sagt, welche Firmware auf der Sonde läuft, und bietet Update ThreadMapper Probe an: Klicken Sie darauf und dann auf Install. Eine Aktualisierung löscht nichts: Die Sonde behält ihr WLAN, ihren Schlüssel und ihr Thread-Netzwerk.

Eine Sonde mit einer Firmware vor 0.8.0 sagt dem Installationsprogramm nicht, was sie ist. Das Installationsprogramm bietet dann Install ThreadMapper Probe an und fragt, ob das Gerät gelöscht werden soll: Lassen Sie Erase device ohne Häkchen.

Läuft auf der Sonde bereits die neueste Firmware, bietet das Installationsprogramm stattdessen Erase User Data an. Das löscht alles, was der Sonde mitgeteilt wurde, genau wie zehn Sekunden langes Gedrückthalten ihrer Taste.

Was Sie wissen sollten

  • Die Sonde öffnet keine Verbindung ins Internet. Sie antwortet in Ihrem eigenen Netzwerk, auf Port 8099, über einfaches HTTP, und kündigt sich dort mit Namen an.
  • Was ihr mitgeteilt wurde – Name und Passwort Ihres WLANs, der Schlüssel und der Thread-Datensatz, falls Sie ihr einen gegeben haben –, behält sie in ihrem eigenen Speicher, nicht verschlüsselt. Die Taste zehn Sekunden lang gedrückt zu halten löscht alles davon.
  • Den Tag an Messwerten hält die Sonde in einem Speicher, den ein Neustart leert, und ein Stromausfall ebenso.
  • Sie ist ein Eigenbau für alle, die einen wollen, kein Produkt. Sie ist nicht Thread-zertifiziert.
  • Das Installationsprogramm auf dieser Seite ist ESP Web Tools von ESPHome, unter der Apache License 2.0. Es läuft in Ihrem Browser und wird von dieser Website ausgeliefert. Es lädt die Firmware von dieser Website und sendet nirgendwohin etwas. Was Sie ihm für das WLAN der Sonde geben, geht durch das Kabel zur Platine; es vermerkt außerdem, was es sendet, als Zahlen, in der Entwicklerkonsole des Browsers, bis der Tab geschlossen wird.
